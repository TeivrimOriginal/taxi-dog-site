# 🌸 BLACK SPRING — сайт инфо-канала флуда

Тема — весенняя готика: параллакс, сакура, ночь/день и такса, которая едет в такси.

## 🛠 Локальный запуск

Просто откройте `index.html` в браузере — сборка не нужна.

```bash
# либо через локальный сервер
python -m http.server 8000
```

## 🚀 Публикация

Сайт задеплоен через **GitHub Pages** (ветка `master`, корень репозитория).

```bash
git add .
git commit -m "update site"
git push origin master
```

Изменения применяются на `https://teivrimoriginal.github.io/taxi-dog-site/` в течение ~1 минуты.

## 📌 Правила флуда (напоминание)

- **Норма:** 70 сообщений в неделю (меньше 70 — кик, 50–70 — пред).
- **Чистка:** каждое воскресенье в 21:00, тишина обязательна.
- **Рест:** 1–3 недели, в день чистки и за день до неё не принимается.
- Треш-контент и реклама — бан навсегда.
- Политика, спам, конфликты, осуждения — предупреждение.
